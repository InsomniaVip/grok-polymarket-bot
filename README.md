# GROK × POLYMARKET BOT FLOOR

> **Version 1.5 · Experimental AI market-intelligence interface**

A cinematic browser-based command center built around a **Grok × Polymarket** concept. The interface visualizes a master AI agent coordinating specialized sub-agents across market discovery, signals, probability, news, risk and simulated execution.

**This repository is a visual / simulation project. It does not connect to Polymarket, place real orders, manage funds, or provide financial advice.**

## ✦ What is inside

- **GROK Command Core** — central orchestration hub for the agent floor.
- **Sub-agent network** — SCOUT, SIGNAL, ODDS, NEWS, RISK and EXEC.
- **Market intelligence stream** — simulated research and system events.
- **Probability Curve** — animated model-probability visualization.
- **Liquidity Flow** — simulated buy/sell activity.
- **Sentiment Wave** — animated sentiment signal.
- **Market contracts** — BTC, Fed, ETH and additional simulated markets.
- **Risk Radar** — exposure, liquidity, slippage and gate state.
- **Workflow pipeline** — `SCAN → SIGNAL → ODDS → RISK → EXEC`.
- **Animated agent floor** — smooth agent movement, routing lines and data particles.
- **Simulation controls** — pause, speed and scan controls.

## ◈ Version 1.5

Version 1.5 is a visual evolution of the original Bot Floor concept. The layout was rebuilt as a three-column command center, the central orchestration core was expanded, live-style analytical panels were added, agent communication was made more visible, and the entire floor was given a deeper blue/cyan/pink holographic atmosphere.

## ▶ Run locally

No build step or dependencies are required.

1. Download or clone the repository.
2. Open `index.html` in a modern browser.
3. Leave the tab open and watch the simulation evolve.

The project is intentionally self-contained: HTML, CSS and JavaScript live in a single browser-ready file.

## ⌨ Controls

| Control | Action |
|---|---|
| `Ⅱ PAUSE` | Pause / resume the simulation |
| `SPEED` | Cycle simulation speed |
| `SCAN` | Trigger a new simulated market scan |
| Click an agent | Select an agent and switch its command context |
| Click a market card | Switch the active simulated market |

## ⚠ Simulation notice

All market values, orders, signals, agent activity and execution states shown by the interface are simulated UI data. Nothing in this repository should be interpreted as a live trading system or financial recommendation.
